# Code Generator

This project is a CLI tool that generates Python functions from natural language descriptions.

## Installation

To install the tool, clone the repository and then install it using pip:

```bash
git clone https://github.com/example/code-generator.git
cd code-generator
pip install .
```

## Usage

To use the tool, run it from the command line with a description of the function you want to create:

```bash
codegenerator "a function that adds two numbers"
```

This will print the generated Python function to the console.
